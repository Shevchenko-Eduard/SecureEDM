## Client

### Технические решения:

Язык программирования: C#
Фреймворк для UI: Avalonia
Работа с DB: Entity Framework Core
Архитектура: Чистая архитектура с паттерном проектирования MVVM в слое предстовления
Database: SQLite

### Требования к клиенту:

- уметь работать офлайн
- кросплатформенность 
- модель расширений для разных алгоритмов создания хеша, ассиметричных ключей и шифрования

### Клиент должен уметь:

- вычислять хеш
- генерировать ассиментричный ключ
- при помощи приватного ключа и на основе хеша получать подпись
- проверять подпись документа

### Что должен хранить клиен:

- вести учет всех документов которые были прикреплены
- подписи документов 
- хеши документов
- историю изменений хеша документов

## BridgeServer

### Технические решения:

Язык программирования: C#
Серверный фреймворк: ASP.NET Core
Работа с DB: Dapper
Архитектура: Чистая архитектура
Database: PostgreSQL

### Может хранить:

- документ
- метаданные документа
- подпись документа
- публичный ключ для проверки подписи
- пава пользователя на тот или иной объект

### Что должен уметь:

- регулировать права доступа на документы

## AuthServer

### Технические решения:

Язык программирования: C#
Серверный фреймворк: ASP.NET Core
Работа с DB: Dapper
Архитектура: Чистая архитектура
Database: PostgreSQL

### Может хранить:

- данные пользователя
- хеш пароля и историю хешей
- сессии
- хеш RefreshToken-а который по сути просто случайно генерируемый ключ привязанный к конкретной сессии и имеющий свой срок годности который каждый раз обновляется при обращении за новым AccessToken

### Что должен уметь:

- регестрация
- идентификация
- аутентификация
- раздача токенов
- проверка токенов
